# 発表計画書（講義版）：交通渋滞シミュレーション研究

## この計画の前提

- **形式**：学生への講義。時間制約なし。
- **最優先事項**：わかりやすさ。詰め込まない。一つの概念を腑に落ちるまで展開する。
- **扱う範囲**：実験1〜5を本編、実験6を「今後の課題」として最後に。

### わかりやすさのための3原則

1. **1スライド1メッセージ**：時間が自由なら、スライドを増やしてでも1枚を軽くする。
2. **たとえ話が主役**：雪だるま・綱引き・水が凍る。数式はスライド隅に置くだけ、口頭では使わない。
3. **「問い→実験→答え」のリズム**：各幕を同じ型で進める。聴き手が「次に何を知りたくなるか」を先回りして問いを立て、実験で答える。

### 発表全体を貫く1つの問い

> **「信号も事故もないのに、なぜ渋滞は生まれるのか。そして、どうすれば消せるのか。」**

実験番号は口頭で出さない。すべて「次にこういう疑問がわきますよね」という地続きの物語にする。

## 各場面の詳細

### 場面0：つかみ — 不思議な縞模様

**目的**：「なぜ?」と思わせる。ここで心をつかめないと後が�​​入らない。

**進め方**：
1. リング状の道路に車を均等に並べたシミュレーションを見せる（アニメーション推奨）。最初は全車スムーズに流れている。
2. 1台がほんの少し減速する。すると渋滞の塊が生まれ、しかも消えずに残る。
3. 時空間プロット（実験1）を見せる：「赤い帯（＝渋滞）が斜めの縞模様になっている。この帯は車の進む向きと**逆向き**に動いている」。
4. **問いを立てる**：「信号も、事故も、工事もありません。なのに渋滞ができて、しかも後ろ向きに進む。これはなぜでしょうか?」
5. Sugiyama et al. 2008 の実車実験（円形トラックに22台、渋滞が自然発生）に触れる：「これは実際の車を使った実験でも確認された、有名な現象です」。

**わかりやすさの工夫**：時空間プロットは初見だと読みにくい。「横が時間、縦が道路上の位置、色が速さ」を、指でなぞりながらゆっくり説明する。1枚に時間をかける。

**スライド**：3枚（タイトル / シミュレーションの様子 / 時空間プロット＋問い）。

---

### 場面1：なぜ渋滞は生まれる? — 雪だるまと綱引き

**目的**：渋滞の原理を、数式ゼロで直感的に理解させる。本発表で最も重要な土台。

**進め方** —— たとえ話を2段階で：

**(1) 雪だるまのたとえ**
1. 前の車が減速したら、後ろのドライバーは安全のため「少し強めに」ブレーキを踏む。これは正しい判断（自分の操作には誤差があるので、余裕を持って強めにかける）。
2. ところがその「少し強め」が後ろに伝わるたびに積み重なる。1台目が10km/h減速 → 2台目は念のため12km/h → 3台目は14km/h … と**雪だるま式に膨らんでいく**。
3. 十数台後ろではもう完全停止。これが「ボトルネックがないのに渋滞ができる」しくみ。
4. （表を見せる：1台目10→5台目21→10台目52→15台目129 km/h、のように増幅が伝わる様子）

**(2) 逆に消える場合もある**
5. もし車間にゆとりがあれば、後ろのドライバーは慌てず、「少し強め」ではなく「少し弱め」に反応できる。すると雪だるまは伝わるうちに**溶けて消える**。

**(3) 綱引きという言葉を導入**
6. つまり渋滞するかどうかは、雪だるまが「育つ」か「溶ける」かの勝負。
7. **キーワードを置く**：「渋滞は、雪だるまを育てる力と、溶かす力の"綱引き"で決まります。今日はこの綱引きを、いろいろな角度から見ていきます」。

**わかりやすさの工夫**：この「綱引き」という言葉を、以降の全場面で繰り返し使う。学生が一度つかんだ言葉を何度も再利用すると、話がバラバラにならない。

**スライド**：3枚（雪だるま連鎖の図 / 増幅の表 / 綱引きの概念図）。

### 場面2：何台から渋滞する? — 境目の発見

**目的**：渋滞は「だんだん」ではなく「突然」始まる、と示す。

**進め方**：
1. **問いを立てる**：「では、車が何台になったら渋滞が始まるのでしょう? 1台ずつ増やして調べてみました」。
2. 実験2のグラフを見せる（速度 vs 台数）。
3. 「台数が少ないうちは、平均速度も、いちばん遅い車の速度も高いまま。スイスイ流れています」。
4. 「ところが、ある台数を超えた瞬間、いちばん遅い車の速度がガクッとゼロに落ちる。ここから渋滞です」。
5. **たとえで締める**：「水を冷やしていくと、0℃で突然氷になりますよね。だんだん固くなるのではなく、ある一点で急に変わる。渋滞も同じで、混み具合がある"境目"を超えると、突然始まるのです」。

**わかりやすさの工夫**：「境目」という言葉を、水が凍るたとえとセットで印象づける。場面4で「境目を正確に測る」と展開するための布石。

**スライド**：2枚（問いのスライド / 実験2グラフ）。

---

### 場面3：混雑だけが原因? — どんでん返し

**目的**：渋滞対策は「車を減らす」だけではない、と気づかせる。物語の転換点。

**進め方**：
1. **問いを立てる**：「渋滞の原因が混雑なら、車を減らすしかありません。でも、本当にそれだけでしょうか?」
2. 「今度は車の数をまったく変えずに、ドライバーの運転スタイルだけを変えてみました」。
3. 運転スタイルを説明：前の車にすぐ詰める「せっかちな運転」か、ゆとりを持つ「慎重な運転」か。
4. 実験3のグラフを見せる（速度 vs 車間時間）。「せっかちな運転だと渋滞。慎重な運転にすると、車を1台も減らしていないのに渋滞が消えて、流れが戻ってきます」。
5. **綱引きに接続**：「これがさっきの綱引きです。慎重な運転は、雪だるまを"溶かす"側に綱を引いている。混雑が綱引きの一方なら、運転スタイルはもう一方なのです」。

**わかりやすさの工夫**：ここで「綱引きには両側がある」と明示する。場面4・5の土台になる。

**スライド**：2枚（問いのスライド / 実験3グラフ）。

---

### 場面4：「境目」を正確に測る

**目的**：これまで目で読んでいた境目を、数値で確定する。研究の精密化パート。

**進め方** —— 3ステップ：

**(1) 問題意識**
1. 「ここまでで"境目"があるとわかりました。でも、グラフを目で見て"だいたいこのへん"と読んでいただけです。これを正確な数字にできないでしょうか?」

**(2) 道具の紹介：渋滞の「勢い」**
2. 「渋滞のもとになる小さな乱れが、時間とともに"育つのか・消えるのか"、その勢いを測りました」。
3. 雪だるまのたとえを再利用：「勢いがプラスなら雪だるまは育って渋滞へ。マイナスなら溶けて消える。ちょうどゼロが"境目"です」。
4. 技術的な中身（対数・直線フィット）は**スライド隅に1行だけ**。口頭では「勢いを数値で測る方法を作りました」で止める。質問されたら答える。

**(3) 結果を3つ**
5. **結果1：境目が数字で出た** — 実験4の3グラフ。「道路の長さ・車の数・運転の慎重さ、3つすべてで、境目がはっきりした数字で出ました」。個々の数値は読み上げず「正確に決まった」ことだけ伝える。
6. **結果2：2つが1つにまとまった** — 密度collapseの図。「道路を長くする実験と、車を減らす実験。別々のはずが、"混み具合"というものさしで描き直したら、ぴったり重なりました。つまり"道路を増やす"のと"車を減らす"のは、渋滞対策として同じことなのです」。
7. **結果3：渋滞の地図** — N×T地図。「混雑と運転の慎重さを同時に動かして、渋滞の地図を作りました。赤が渋滞、青が自由に流れる領域。黒い線が、その境界＝綱引きの均衡線です」。

**わかりやすさの工夫**：結果を3つ一度に出すと重い。1枚ずつ「これが言いたいのはこれ」と一文でまとめてから次へ。急がない。

**スライド**：5枚（問題意識 / 勢いの説明 / 結果1 / 結果2 / 結果3）。

### 場面5：全員が慎重じゃなくても? — クライマックス

**目的**：発表の山。「全員でなく一部でいい」という現実的で力強い結論。

**進め方**：
1. **問いを立てる**：「ここまでの話には、こっそり前提がありました。"全員が同じ運転をする"という前提です。でも現実の道路は、慎重な人もせっかちな人も混じっています」。
2. 「そこで問いを進めました。**慎重なドライバーが"何割"いれば、道路全体の渋滞は消えるのか?**」
3. 「慎重な人とせっかちな人を1つの道路に混ぜて、慎重派の割合を0%から100%まで動かしました」。
4. 実験5のグラフを見せる。「慎重派が増えるほど、渋滞の勢いは下がっていきます。そして——」
5. **核心**：「約72%、4人に3人弱が慎重に運転すれば、残りがせっかちなままでも、道路全体の渋滞は消えました」。
6. **意味を語る**：「全員が完璧な運転をする必要はない。4人に3人で十分なのです。これは現実的な数字です」。

**わかりやすさの工夫**：「72%」より「4人に3人」と言い換える。割合より分数のほうが直感に訴える。グラフのばらつきの帯にも軽く触れる：「ぎりぎり72%だと、誰がどこを走っているかの運で揺れます。確実に消すなら8割が安全」。正直さが信頼になる。

**スライド**：3枚（問いのスライド / 混在の説明図 / 実験5グラフ）。

### 場面6：まとめ＋今後の課題

**目的**：着地させ、さらに研究の奥行きを見せる。

**(1) まとめ — 3つだけ**
学生が持ち帰れるのは3つまで。これだけ言う：
1. 渋滞は、信号も事故もなくても自然に生まれ、しかも"境目"がある。
2. 原因は混雑だけではない。運転の慎重さも同じくらい効く。
3. 渋滞は「混雑」と「慎重さ」の綱引き。そして、全員でなく4人に3人が慎重なら、渋滞は消える。

**(2) 持ち帰りメッセージ**
> 「渋滞をなくすのに、新しい道路を作る必要はないかもしれません。私たちのうち4人に3人が、少し運転を変えるだけでいいのです」。

**(3) 今後の課題 — 仮説を1つ提示**
1. 「最後に、今わたしが追いかけている仮説を紹介します」。
2. 「実験では台数を固定していました。でも本当に知りたいのは、"道路の大きさそのもの"が何を決めているか、です」。
3. **仮説を述べる**：「**必要な慎重派の人数は、その道路に今何台いるかではなく、その道路に最大何台詰め込めるか——道路の"容量"だけで決まるのではないか**、という仮説です」。
4. 「もしこれが正しければ、"この道路は最大○台入る。だから○人が気をつければ、実際に何台走っていても渋滞は消える"と言えることになります」。
5. 「これを確かめるのが、次の実験です」。

**わかりやすさの工夫**：今後の課題は「やり残し」ではなく「次のワクワク」として語る。発表が前向きに終わる。

**スライド**：3枚（まとめ / 持ち帰りメッセージ / 今後の課題）。

## 講義を成功させる進め方のコツ

1. **各場面の頭で必ず「問い」を声に出す**：「次にこういう疑問がわきますよね」と。学生が自分で考える隙を作る。
2. **たとえ話を一貫させる**：雪だるまと綱引きを最後まで使い続ける。新しいたとえを途中で増やさない。
3. **グラフは指でなぞる**：軸が何か、線が何を意味するか、ゆっくり。初見の図は1枚に時間をかける。
4. **数値を読み上げない**：「L\*は516.3メートルで」のような細かい数字は言わない。「正確な境目が出た」で十分。例外は「72%＝4人に3人」だけ。これは結論なので強調する。
5. **山場（72%）の前で一拍置く**：「ここからが今日いちばん伝えたいことです」と前置きしてトーンを変える。
6. **今後の課題は明るく**：「まだわからないこと」を不安ではなくワクワクとして語る。

## 想定質問と回答

| 質問 | 回答方針 |
|---|---|
| 渋滞の「勢い」はどう測った? | 小さな乱れが時間とともに何倍になるかの割合。技術的には対数を取って傾きを測った、と一言。 |
| なぜリング（環状）道路? | 道路の端の影響を消し、渋滞のしくみだけを純粋に取り出すため。実車実験も同じ理由で円形トラックを使った。 |
| 現実の道路には車線変更も信号もある | その通り。本研究は最も単純な設定での第一歩。車線変更や信号の追加は今後の発展。 |
| 72%は道路の混み具合で変わるのでは? | 変わる。今回は1つの混雑度での値。混雑度を変えたらどうなるかが、まさに今後の課題の仮説。 |
| シミュレーションは何回回した? | 実験全体で千回以上。1回1秒未満なので、全部で数分〜十数分。 |
| 「慎重な運転」は具体的に何? | 前の車との車間時間を長めに取ること。モデルでは2.0秒。せっかちは0.8秒。 |
