# 環状道路 交通渋滞シミュレーション

リング状の道路に車を並べ、IDM(Intelligent Driver Model)で動きを計算するMASシミュレーションです。
信号もボトルネックもないのに渋滞波が自然発生する現象(Sugiyama 2008 で有名な現象)を数値的に再現し、
**どの条件で渋滞が起きるか・どうすれば消えるか**を体系的に調べた研究プロジェクト。

---

```

```

## 実験を動かす

順番依存はありません。それぞれ独立に動きます。

### 基礎の2実験(実験2・3)

```
python experiments.py
```

車の台数と車間時間を1つずつ動かして、渋滞の境目をグラフで見る。所要 数十秒。

### 渋滞の境目を数値で確定(実験4)

```
python experiment4_growth.py
```

3つの設定(道路長・台数・車間時間)それぞれで「成長率がゼロになる」臨界値を求める。所要 約2分。

### 渋滞の地図を描く(実験4の拡張)

```
python experiment4_NT_map.py
```

台数と車間時間を同時に動かし、2次元の安定性マップを作る。所要 1〜2分。

### 慎重派の必要割合を調べる(実験5)

```
python experiment5_mixed.py
```

慎重派とせっかち派を混ぜて、必要な慎重派の割合を求める。所要 約3〜5分。

### アニメーション(発表のつかみ用)

```
python visualize_animation.py
```

リング上の車の動きをアニメーションで見て、GIFとして保存する。所要 30秒〜数分。

## 主な発見(数字だけ)

詳しくは `研究サマリー.md` に。

- 渋滞の臨界値:**道路長 516m**, **台数 19.5台**, **車間時間 1.71秒** (それぞれ他2つ固定)
- 道路を伸ばすことと車を減らすことは、**密度というものさしで同じ効果**
- 慎重なドライバーが **約72%(4人に3人弱)** いれば、残りがせっかちでも渋滞は消える
